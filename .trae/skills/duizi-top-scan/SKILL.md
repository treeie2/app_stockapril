# 对子顶+上影线扫描

## 核心定义

### 对子顶四种⭐⭐⭐类型（独立分类）

| 类型 | 标签 | 定义 | 示例 | 检测顺序 |
|:----:|------|------|------|:--------:|
| 🥇 | **完全对子顶** | AB.AB: 整数末两位==小数两位 | 23.23, 148.48, 111.11 | 1st |
| | | AB.BA: 整数末两位反转==小数两位 | 12.21, 23.32 | |
| 🥇 | **AABB顶** | 整数末两位相同+小数两位相同+AA≠BB | 11.22, 22.33, 55.11, 99.44 | 2nd |
| 🥇 | **顺子顶** | 四位连续递增/递减（末2+小数2） | 12.34, 23.45, 43.21 | 3rd |
| | | 五位连续（末3+小数2） | 123.45, 234.56 | |
| ~~⭐⭐~~ | ~~尾数对子顶~~ | ~~小数两位相同（排除.00）~~ | ~~24.88, 35.55~~ | ~~已移除~~ |
| ~~⭐~~ | ~~普通对子顶~~ | ~~整数关口 .00~~ | ~~10.00, 55.00~~ | ~~已移除~~ |

### 关键指标

- **上影倍数** = 上影线长度 / max(实体长度, 0.001)
  - 上影>3x + 回落>3% → 标准对子顶压力信号
- **回落幅度** = (最高价 - 现价) / 最高价 × 100%（排序依据，降序）
- **上影占比** = 上影线长度 / (最高-最低) × 100%

### 筛选门槛

- 上影占比 ≥ 30%，上影倍数 ≥ 1.2x
- 排除 ST / 退市 / 停牌

### 信号置信度分级（不改变筛选，仅排序用）

对子顶信号按以下维度分级，高置信度信号优先展示：

| 维度 | 高置信度 🔴 | 中等 🟡 | 低 ⚪ |
|:----|:-----------|:--------|:------|
| **位置** | 近20日高位（>80%分位） | 中位（30~80%） | 低位（<30%） |
| **量能** | 放量（量比>1.5）→ 主力出货可信 | 平量（0.8~1.5） | 缩量（<0.8）→ 偶然对子概率高 |
| **主力资金** | 当日主力净流出 | 资金持平 | 主力净流入 → 可能洗盘非顶部 |
| **CCI** | CCI > +200 或 CCI从高位回落（单日降幅>50）→ 超买+拐头 | CCI +100~+200 | CCI < +100 |
| **KDJ** | J > 90 或 J从高位死叉 → 严重超买 | J 70~90 | J < 70 |
| **OBV** | 连续2日递减 或 单日急降（降幅>前日×30%）→ 资金出逃 | OBV走平 | OBV仍向上 → 资金未跑 |

> **位置**仅作为标注参考，**不计入扣分**（对子顶本身已是价格信号，重复加权会导致误扣）。扣分只算量能/资金/CCI/KDJ/OBV五项。

**输出时标注各项组合判断**：
```
对子顶 23.23
  位置：🔴 高位（近20日87%）→ 标注参考
  量能：🔴 放量（量比2.1）→ 主力出货
  资金：🔴 主力净流出-2800万 → 资金出逃
  CCI：🔴 +285→+190（单日降95）→ 超买回落
  KDJ：🔴 J死叉 98→80 → 短线见顶
  OBV：🟡 走平 → 资金未明显出逃，观察
  → 扣分项：4/5项指向压力，强卖出信号

对子顶 11.22
  位置：⚪ 低位（20%）→ 标注参考
  量能：⚪ 缩量（量比0.7）
  资金：⚪ 主力净流入+120万
  CCI：⚪ +80 正常
  KDJ：🟡 J=72中性
  OBV：🟢 向上 → 资金仍在流入
  → 扣分项：0/5项指向压力，仅标注留意
```

### 与N字/主升浪集成
- 扣分项（量能/资金/CCI/KDJ/OBV）中 ≥2项🔴 → 扣分或降C级
- 扣分项中 1项🔴 → 标注留意，不扣分
- 扣分项中 0项🔴 → 不处理（偶然对子）
- **N字回踩期豁免**：N字处于回踩阶段（左锋后≤5日，未完成右锋）时，对子顶信号屏蔽扣分，仅标注参考

### 检测优先级

完全对子 → AABB → 顺子 → 尾数对子 → 普通对子（与底扫一致）

## 检测算法

与底扫共享 `classify_duizi()` 函数，仅标签字符串不同（"完全对子顶"/"AABB顶"/"顺子顶"/"尾数对子顶"/"普通对子顶"）。

## 执行流程

### 扫描

```bash
python3 ~/.hermes/scripts/duizi_top_scan.py
```

30并发，batch=200，~25秒。全量输出不截断。

### 数据富化

与底扫共享 `duizi_enrich.py`，自动处理两种数据。

**对子顶特有的富化逻辑：**
- 涨跌幅列标题：`5日·10日·20日↑`
- 颜色规则：🟢绿=跌(压力小) 🔴红=涨(压力大)——与底扫相同不翻转符号
- 资金流覆盖 level3+level2

### 输出格式

仅⭐⭐⭐（完全对子顶+AABB顶+顺子顶），富化图片形式投递。
