兆易创新（603986.SH/03986.HK）价值投资深度研究报告：总市值1954亿背后的产业逻辑与估值重塑

在半导体行业经历过2022年至2023年的剧烈去库存周期后，2024年成为了行业周期的关键转折点，而2025年则见证了以端侧AI和国产替代深水区为核心逻辑的爆发式增长1。截至2026年1月16日，兆易创新（GigaDevice）在A股市场的总市值正式触及1954.15亿元关口，这一里程碑式的数字不仅是对其过去二十年技术积淀的肯定，更是资本市场对其作为国内“感存算控连”全方位布局龙头的深度认可2。

第一章全球半导体新周期：从弱复苏到结构性高增长的跨越
==========================

全球半导体产业在2024年实现了6276亿美元的销售额，同比增长19.1%，这标志着行业已彻底走出低谷，开启了新一轮的扩张周期1。兆易创新正处于这一周期的核心受益位置，其业务版图深度契合了当前行业发展的两大主旋律：AI基础设施的下沉与利基市场的份额重构。

1.1 存储器市场的结构性分化与机遇
------------------

2024年全球存储芯片销售额达到1651亿美元，同比大幅增长78.9%1。这种增长主要源于AI服务器对高带宽存储器（HBM）的极致渴求，以及由此引发的传统DRAM和Flash产能被排挤后的价格回升。进入2025年，这种传导效应开始深入利基市场。随着三星、SK海力士等国际原厂逐步退出DDR3、DDR4等中低端利基型DRAM产能，以转向利润更丰厚的HBM和DDR5，兆易创新凭借其与本土晶圆代工厂长鑫存储的深度战略合作，成功填补了这一市场空白4。

1.2 端侧AI：从概念爆发到硬件落地的驱动力
-----------------------

2025年被称为AIPC与AI手机的元年。在端侧AI的推动下，智能手机的平均售价（ASP）预计将增至385美元，而AIPC相较于传统PC具备10%-15%的溢价空间1。这种溢价并非仅仅来源于软件溢价，更多是硬件配置的全面升级。端侧模型（On-deviceModels）的运行需要更高容量的非易失性存储（NORFlash）来支撑安全启动（SecureBoot）和高速缓存，这为兆易创新占据全球第二地位的NOR Flash业务提供了持续扩容的市场空间1。

第二章 存储业务：稳固基本盘并向利基型DRAM纵深发展
===========================

作为兆易创新的起家之本，存储业务在2025年表现出了极强的韧性与扩张性。通过在工艺制程上的领先迭代，以及在利基市场的精准卡位，公司已成为全球存储格局中不可忽视的重要力量。

2.1NORFlash：45nm工艺引领下的全球话语权
---------------------------

兆易创新在2025年率先实现了45nm节点NORFlash的大规模量产，这使其在技术代际上与国际巨头如美光、赛普拉斯等维持在同一梯队5。45nm工艺相较于传统的65nm，不仅能够显著减小芯片面积从而降低成本，更在低功耗性能上实现了质的飞跃，这对于电池容量受限的穿戴设备和AI眼镜等端侧AI设备至关重要1。

2.2 利基型DRAM：战略绑定长鑫存储的爆发力
------------------------

兆易创新在DRAM领域的布局并非简单的“跟风”，而是通过“设计+投资+代工”的三位一体模式构建了深厚壁垒。公司持有长鑫存储1.88%的股权，并与其确立了直到2030年的独家代工合作关系。这种战略绑定在2025年展现出了巨大的价值：在获取代工资源方面，兆易创新具备了其他Fabless厂商难以企及的稳定性和确定性4。

2025年上半年，公司利基型DRAM市占率提升至1.7%，全球排名升至第七位4。尽管绝对份额仍有提升空间，但其增长势头极其强劲，2025年DRAM业务营收有望突破8亿元，同比实现翻番增长4。随着公司DDR4、DDR3L等系列产品在机顶盒、电视、智能家居等领域的渗透率提升，DRAM业务已正式成为公司的第三增长曲线4。

2.3SLCNAND：海外原厂淡出后的空间置换
-----------------------

在NANDFlash市场，国际大厂正加速淡出低容量的SLCNAND市场，将重心转向高堆叠层数的3DNAND。兆易创新利用自身在利基市场的渠道优势，通过成熟的工艺节点提供高可靠性的SLCNAND产品，满足工业及网络通信领域对长生命周期的需求5。这种“错位竞争”策略确保了存储业务在整体下行周期中仍能维持较高的毛利率水平。

第三章MCU业务：从通用市场向高端工控与车规的跨越
=========================

如果说存储业务是兆易创新的“现金牛”，那么MCU业务则是其提升估值上限的“明星业务”。

3.132位Arm通用型MCU的绝对领先地位
----------------------

兆易创新是中国排名第一的32位Arm通用型MCU供应商。2025年，其在国内32位通用MCU市场的份额达到19%，成功超越了意法半导体（ST）、瑞萨等长期占据中国市场的国际巨头4。

3.2 车规MCU：打破国际垄断的新高地
--------------------

在汽车电子领域，MCU的准入门槛极高，长期被恩智浦（NXP）、瑞萨、英飞凌等厂商统治。兆易创新的GD32A系列车规MCU通过两年的验证期后，在2025年迎来了放量1。公司在车规MCU市场的市占率已达12%，2025年的目标是提升至15%，通过进入动力电池管理、车身控制及智能座舱等核心环节，兆易创新正逐步打破海外大厂的垄断格局4。

3.3 工业与AI服务器的新契机
----------------

MCU业务的另一个增长点在于AI服务器。随着光模块产品线的技术突破，兆易创新的MCU已成功敲开AI服务器和工业机器人的大门4。在AI服务器的电源管理、系统控制等模块中，高精度、高响应速度的MCU需求量显著增加。这种“存储+控制+AI接口”的多元产品矩阵，为公司提供了单一产品线不具备的系统级协同优势4。

第四章传感器与模拟芯片：完善“感存算控连”生态闭环
=========================

兆易创新并不止步于存储与计算，通过内生增长与外延并购，公司正在构建一个完整的芯片生态。

4.1 传感器：深耕信号链与算法解决方案
--------------------

公司的传感器业务（指纹识别及触控芯片）目前在国内排名前三，虽然2024年营收占比仅为6.09%，但在手机及智能穿戴领域拥有稳定的客户基础4。公司目前的研究方向已从单一的硬件销售转向“传感器+信号链+算法”的整体解决方案，力争在物联网全生态中占据核心节点4。

4.2 模拟产品：收购苏州赛芯的战略考量
--------------------

2024年对苏州赛芯的收购是兆易创新完善产品线矩阵的关键一步5。赛芯在电源管理及保护芯片领域的积淀，能够与MCU及存储产品形成互补，为客户提供更完整的PCB级解决方案。这种整合

策略不仅提升了单机价值量，更通过深度绑定客户需求，增强了抗风险能力。

兆易创新在1954亿市值下的投资价值，最直接的支撑来自于其财务数据的强劲反弹。

5.1 营收与净利润的加速增长
---------------

2025年前三季度，公司实现营业收入68.32亿元，同比增长20.92%；归母净利润10.83亿元，同比增长30.18%5。这一数据表明，公司已摆脱了2023年的业绩泥潭，进入了新一轮的增长快车道。

根据38家机构的一致预期，2025年全年归母净利润将达到16.16亿元左右，同比增速高达46.61%。

5.2 毛利率修复的内在逻辑
--------------

毛利率的提升是2025年财务表现中的一大亮点，预计将从2024年的36.2%修复至39.4%1。这一修复主要归因于：

1.  产品结构优化：高毛利的车规MCU和45nmNORFlash出货占比提升。
  
2.  产能利用率提高：随着下游工业及汽车需求回暖，Fabless模式下的单位代工成本在规模效应下被摊薄。
  
3.  利基市场价格企稳：特别是DRAM价格在2025年下半年的企稳回升，直接带动了公司DRAM业务的盈利修复1。
  

第六章估值体系分析：总市值1954亿的合理性与挑战
=========================

在2026年1月16日，兆易创新触及涨停，股价达280.46元，总市值1954.15亿元2。对于一家芯片设计公司而言，如何理解这一估值水平？

6.1PE、PB与PS的多维评估
----------------

截至2026年1月中旬，公司的动态市盈率（PETTM）在130.01至144.4之间波动，市净率（PB）约为9.67至10.683。从绝对数值看，这一估值水平处于历史高位区间。

然而，半导体领军企业的估值逻辑通常需要结合行业周期和成长确定性。相较于海外同类巨头，如美光、瑞萨等，兆易创新虽然在PE上更高，但其营收增速和市场份额扩张速度（特别是从零到一的国产替代过程）具有明显的溢价潜力。机构预测2025年每股收益为2.43元，对应当前股价的动态PE仍处于一个反映了强预期的合理溢价范围内7。

6.2 技术投入与长期壁垒
-------------

2025年上半年，公司研发投入约5.68亿元，占营收比例为13.6%6。虽然这一比例略低于国际顶尖大厂，但在国内半导体企业中已名列前茅。公司研发的重点在于先进制程的导入和复杂算力芯片的开发，这种持续的高强度投入是维持其1954亿市值不被“泡沫化”的核心护城河。

第七章 全球化资本运作：A+H双平台构建战略
======================

2026年1月13日，兆易创新在香港联交所主板正式挂牌上市（03986.HK），开启了“A+H”双资本平台时代10。

7.1 H股上市的募资与战略意图
----------------

公司H股最终定价为162港元，净募资额约为46.11亿港元8。这次融资的用途非常明确且具侵略性：约35%的资金将用于战略性行业相关的投资及收购8。这表明兆易创新在现有的业务版图之外，正积极寻求通过国际资本力量获取全球先进技术或市场渠道。

7.2 全球视野下的估值重塑
--------------

在香港上市意味着兆易创新正式进入了国际主流机构投资者的配置名单。H股的定价和交易表现将与A股形成联动，有助于公司平滑单一市场的估值波动，并为未来的全球化人才引进和技术合作提供更便利的激励工具。

第八章技术对比：与国际巨头的差距及追赶路径
=====================

在享受高估值的同时，作为行业专家，必须清醒地认识到兆易创新与国际顶级巨头的代际差距。

8.1存储制程：19nmvs1αnm
------------------

在DRAM领域，三星已经实现了1α纳米制程的量产，而兆易创新的主力产品仍处于19纳米制程6。在追求极限存储密度的道路上，这种代际差距意味着公司目前主要活跃在利基市场（NicheMarket），而非主流的高容量数据中心市场。

8.2MCU工艺：28/40nmvs16nm
----------------------

在MCU市场，国际巨头已经开始规模化量产基于16nm甚至是更先进制程的产品，而兆易创新的主力产品线仍基于40nm和28nm工艺6。虽然对于通用型MCU而言，40nm已能满足绝大部分工业和汽车需求，但在追求极致算力和超低功耗的高端AIoT场景，先进制程的追赶仍是公司长期的必修课。

第九章投资风险与应对
==========

尽管2025年的业绩表现亮眼，但投资者仍需警惕以下风险点：

1.  地缘政治影响供应链稳定性：尤其是在先进工艺的代工资源获取方面，外部环境的变动可能导致产能受限1。
  
2.  市场竞争加剧导致毛利率承压：虽然国际大厂在退出利基市场，但国内其他竞争者的入局可能引发新的价格战4。
  
3.  技术路径更迭风险：如存储技术从传统的DRAM向新型存储技术（如MRAM、RRAM）的潜在演进。
  
4.  资本市场波动：2026年1月的高估值水平对后续的业绩兑现提出了极高的要求，任何业绩不及预期的表现都可能导致估值的快速回调7。
  

第十章结论：1954亿市值是起点而非终点
