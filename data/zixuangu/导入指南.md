## 一、通达信导入（.blk 文件）

通达信使用**板块文件**（`.blk`）来管理自选股分组。

### 步骤

1. **找到通达信板块目录**

   打开通达信安装目录，进入 `T0002/blocknew/`（如果该目录不存在则新建）：
   ```
   例如：D:\new_tdx\T0002\blocknew\
   ```

2. **复制 .blk 文件**

   将 `output/` 下所有 `.blk` 文件复制到 `T0002/blocknew/` 目录下。

   例如复制 `光刻胶-全产业链.blk` 到：
   ```
   D:\new_tdx\T0002\blocknew\光刻胶-全产业链.blk
   ```

3. **重启通达信**

   关闭并重新打开通达信。板块会自动出现在"自定"板块列表中。

4. **查看板块**

   通达信主界面 → 底部点击 **"自定"** → 即可看到所有导入的题材板块。

5. **一键导入脚本**（可选）

   ```powershell
   # 修改 TDX_PATH 为你的通达信安装目录
   $TDX_PATH = "D:\new_tdx\T0002\blocknew"
   Copy-Item "E:\firebase++\wechat_query\output\*.blk" -Destination $TDX_PATH -Force
   ```

### 格式说明

`.blk` 文件内容示例：
```
600207
002243
300054
603650
...
```
每行一个 6 位股票代码，大盘股（6开头）和中小创（0/3开头）均可。

## 二、同花顺导入（.sel 文件）

同花顺使用**自选股文件**（`.sel`）来管理自选股分组。

### 方法一：逐个导入（推荐）

同一个花顺的"自选股"默认是一个列表，如需分组，可用"自选股分组"功能：

1. **打开同花顺**
2. 点击菜单 **"工具"** → **"自选股设置"**（或快捷键 `Ctrl+F10`）
3. 点击 **"导入"** → **"从文件导入"**
4. 选择一个 `.sel` 文件（如 `光刻胶-全产业链.sel`）
5. 导入后，右键这些股票 → **"移动到分组"** → **"新建分组"** → 输入分组名（如"光刻胶"）
6. 重复以上步骤导入其余板块

### 方法二：批量导入所有板块到一个文件

如果想一次性全部导入：

```powershell
# 将所有 .sel 合并为一个文件（同花顺支持批量导入）
Get-Content "E:\firebase++\wechat_query\output\*.sel" | 
    Sort-Object -Unique | 
    Set-Content "E:\firebase++\wechat_query\output\全部自选.sel" -Encoding UTF8
```

然后导入 `全部自选.sel` 即可。

### 格式说明

`.sel` 文件内容示例：
```
0,002243
0,300054
1,600207
1,603650
...
```
格式：`市场代码,股票代码`
- `0` = 深圳（00xxxx/30xxxx）
- `1` = 上海（60xxxx/688xxx）

## 三、快捷操作

### 批量复制所有板块文件到通达信

```powershell
# 1. 修改下面路径为你的通达信目录
$TDX = "D:\new_tdx\T0002\blocknew"

# 2. 创建目录（如不存在）
New-Item -ItemType Directory -Force -Path $TDX

# 3. 复制所有 .blk 文件
Copy-Item "E:\firebase++\wechat_query\output\*.blk" -Destination $TDX -Force

# 4. 验证
Get-ChildItem $TDX\*.blk | ForEach-Object { Write-Host $_.Name }
```

### 同花顺完整导入脚本

```powershell
# 同花顺自选股文件存放路径（通常在这里）
$THS = "$env:APPDATA\Hexin\selfstock"
# 如果上面路径不对，请在软件里点击"导出"查看实际路径

# 将所有板块股票汇总为一个文件
$all = Get-Content "E:\firebase++\wechat_query\output\*.sel" | Sort-Object -Unique
$all | Set-Content "$THS\全部题材.sel" -Encoding UTF8
Write-Host "已生成全部题材.sel，共 $($all.Count) 只股票"
```

## 四、注意事项

1. **同花顺分组**需要手动创建，不支持直接导入分组名
2. 通达信**一次只能显示一个板块**，可在"自定"中快速切换
3. 如果通达信已打开，需要**重启**才能看到新板块
4. 同一个股票可以出现在**多个板块**中，互不影响
5. 推荐先导入几个你最关注的题材试试效果
