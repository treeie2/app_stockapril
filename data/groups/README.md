**注意事项**：
- `stocks` 数组存储的是**股票名称**（中文），不是代码
- 前端通过 `groups.json` 反向匹配股票名称来显示"该股所属分组"
- 分组中可能包含不在 stocks_master 投研库中的真实 A 股

## 📋 分组创建与维护流程

### 新建分组

当用户提供分组定义时（如"分组：+MLCC：麦捷科技、国瓷材料..."）：

1. **首先写分组定义文件** `_create_groups.py`（一次性脚本）
2. 脚本内容：读取 `groups.json`，添加新 group，写入
3. 运行该脚本
4. **验证**：检查每个分组中的股票名称是否准确（不要纯代码、不要 HK 股混入）

### 维护检查

```bash
# 1. 审计分组（查找缺失股票、无效代码）
python _audit_groups.py

# 2. 补充缺失股票（根据原始描述）
python _fix_groups.py

# 3. 清理纯数字代码 + 模糊匹配股票名
python _fix_final.py

# 4. 强制添加不在 master 中的真实 A 股
python _force_add.py
```

### 常见问题

| 问题 | 原因 | 修复 |
|------|------|------|
| 股票名显示为纯数字代码 | TDX BLK 导入时代码未映射 | 运行 `_fix_groups.py` |
| 分组中缺少描述里提到的股票 | 创建时遗漏 | `_force_add.py` 补入 |
| 股票名不在 stocks_master 中 | 该 A 股未被投研库收录 | 不影响分组显示，后续处理研报时自动入库 |
| HK 股混入 A 股分组 | TDX 导入未过滤 | 在脚本中 `HK_NON_A` 列表移除 |
| 分组为"晶圆中测探针卡"等空分组 | 创建时未填入股票 | 需手动补充 |

## ⚠️ 重要注意事项

1. **分组名不要重复**：TDX 导入时 "铜箔"、"折叠屏" 可能与手动分组重名，会自动跳过
2. **股票名用中文**：不要用纯代码（如 `688682`），用股票名称（如 `霍莱沃`）
3. **非 A 股过滤**：锦欣生殖、贝康医疗等 HK 股需从分组中移除
4. **每只股票可在多个分组**：前端反向匹配时会显示所有所属分组
